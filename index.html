Database Google Sheets

Sinkronisasi data otomatis tanpa biaya langganan.

Paste URL deployment Apps Script Anda di sini. Harus berakhiran /exec. Kosongkan jika hanya ingin memakai mode lokal/offline.

Cara Setup Database ke Spreadsheet Anda:

  1. Buka Google Sheets & buat spreadsheet baru bernama "DB Percetakan".
  2. Klik menu Ekstensi > Apps Script di dalam spreadsheet tersebut.
  3. Copy & Paste seluruh kode script di bawah ini untuk menggantikan kode yang ada.
  4. Klik Terapkan (Deploy) > Deployment Baru.
  5. Pilih jenis: Aplikasi Web.
    PENTING: Atur "Yang memiliki akses" menjadi Siapa saja (Anyone). Lalu klik Deploy.
  6. Copy URL Aplikasi Web yang muncul, lalu paste ke kolom input di atas!
